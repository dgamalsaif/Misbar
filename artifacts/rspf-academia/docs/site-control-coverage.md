# جرد الصفحات وأدوات تحكم مسبار

هذه خريطة لما يمكن تعديله من إعدادات الموقع، وما يبقى بيانات تشغيلية أو صلاحية محمية. لا تغيّر الإعدادات مسارات الصفحات أو نظام الدخول أو قاعدة البيانات.

## الوصول والصلاحيات

بعد دخول المالك، افتح `/admin` ثم «المحتوى والحقول والمظهر» ثم «مسبار — تجربة الموقع». تغييرات الاسم والشعار والمظهر والمحتوى العام تحفظ من لوحة المالك. واجهة الإدارة تخفي أدوات الموقع عن غير المالك، وخادم الإعدادات يطلب صلاحية المالك عند الحفظ؛ جلسة المنسق لا تمنح هذه الصلاحية.

## الصفحات وتغطية التحكم

| الصفحة أو المسار | المحتوى والبيانات | إعدادات العرض المتاحة |
| --- | --- | --- |
| `/` | مقدمة مسبار، الخدمات، الفرص المفتوحة الحقيقية، قوائم الجامعات والدول والمجلات، المسارات والخطوات، مركز المعرفة والأسئلة والدعوة الختامية | ترتيب الأقسام وإظهارها، النصان العربي والإنجليزي، أزرار وروابط، صورة المقدمة، أسماء الجامعات والدول والمجلات، ألوان الموقع، تشغيل الحركة ومدتها |

| `/coordinator/dashboard` و`/coordinator/submissions` | لوحة المنسق والسجلات | بيانات تشغيلية حسب صلاحية الحساب؛ لا تفتح إعدادات الموقع العامة |
| `/admin` و`/admin/submissions` | أدوات الإدارة وسجلات المشاركين | لوحة المالك هي موضع التحكم العام؛ السجلات تظل بيانات محمية ولا تُحوّل إلى نصوص عرض |
| `/owner-admin` و`/sign-in` و`/sign-up` | دخول المالك | لا تُعدّل إعدادات المظهر صلاحيات الحساب أو أسرار الدخول |
| أي مسار غير معروف | صفحة غير موجودة | عنوان ونص وزر الرجوع؛ المسار نفسه لا يتغير |

## مجموعات الإعدادات

- **الهوية:** الاسم العربي والإنجليزي، الشعار القابل للرفع والإزالة، أيقونة التطبيق، ألوان التطبيق، ووسوم الاسم.
- **المظهر:** ألوان الموقع، الخلفيات، الخطوط وأحجامها، الأزرار والبطاقات، الزوايا والكثافة والحركة.
- **القائمة والتذييل:** أسماء الروابط وترتيبها وظهورها، النصوص، أعمدة التواصل والروابط.
- **الرئيسية:** ترتيب الأقسام، إظهارها وإخفاؤها، نصوص المقدمة والخدمات والفرص والمسارات والخطوات والمحتوى الختامي.
- **الجامعات والدول:** قوائم ثنائية اللغة قابلة للإضافة والحذف والترتيب. الأسماء الافتراضية تعريفية وليست ادعاءً بالشراكة أو الاعتماد؛ يمكن للمالك تعديلها أو حذفها.
- **المجلات:** يمكن للمالك إضافة أسماء المجلات وتعديل بياناتها وترتيبها وحذفها. الشريط يعرض الأسماء المحفوظة فقط، من دون شعارات أو ضمان نشر؛ المجلة المستهدفة لكل فرصة تبقى من بيانات الفرصة.
- **الحركة:** يمكن إيقاف حركة أشرطة الدول والجامعات أو المجلات، وضبط مدة دورة كل شريط. إعداد حركة الموقع العام واحترام تفضيل تقليل الحركة يبقيان فعالين.
- **SEO:** عنوان ووصف وصورة مشاركة لكل صفحة عامة. الصفحات الخاصة لا تُفهرس؛ وتغيير النصوص لا يضمن ترتيباً معيناً في محركات البحث.

## معاينة وحفظ وتطبيق التغييرات

تظهر مسودة تجربة الموقع في المعاينة قبل الحفظ. عند الحفظ، يتحقق الخادم من القيم ويكتبها في التخزين الدائم؛ يعرض التطبيق رسالة خطأ عند فشل الطلب بدلاً من تأكيد نجاح غير حقيقي. إعادة الضبط تتطلب التأكيد وتعيد إعدادات التجربة ولا تحذف الفرص أو التسجيلات.

تحديث اسم وأيقونة التطبيق القابل للتثبيت يحدّث بيانات الموقع والبيان والأيقونات التي يطلبها التطبيق. لا تضمن المتصفحات تحديث اسم أو أيقونة نسخة مثبّتة فوراً؛ قد يتطلب ظهور التغيير إعادة فتح التطبيق أو إعادة تثبيته وفق المتصفح ونظام التشغيل. الروابط والنطاق الحاليان لا يتغيران.
