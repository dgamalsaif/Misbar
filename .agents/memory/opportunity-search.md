---
name: Opportunity search rules
description: Product decisions for participant-facing opportunity search fields.
---

The participant portal's country filter refers to the opportunity's country, not the participant's residence. Each opportunity may have an optional registration closing date; do not infer these values for existing opportunities. Search and filter results must respect both per-opportunity public visibility and the global opportunity-details switch.

**Why:** The user chose opportunity country as the filter meaning and approved an optional closing-date field.

**How to apply:** Preserve these rules when changing opportunity creation, imports, public cards, or participant search.
